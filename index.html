Scripts da Equipe

Ferramentas que agilizam o dia a dia no Salesforce, no SDE e no Saúde no Campo. Instale o Tampermonkey uma vez e depois é só clicar em Instalar no script que quiser.

Como instalar

Leva menos de 2 minutos. Os passos 1 e 2 só são feitos na primeira vez.

1

Instale o Tampermonkey

É uma extensão gratuita do navegador que executa os scripts. Clique abaixo e depois em “Usar no Chrome” (ou “Obter”).

⬇ Instalar Tampermonkey
2

Libere a permissão de scripts

O Chrome e o Edge exigem uma permissão extra:

  1. Clique no ícone de quebra-cabeça 🧩 ao lado da barra de endereço.
  2. Nos 3 pontinhos do Tampermonkey, escolha Gerenciar extensão.
  3. Ative “Permitir scripts de usuário”.
  4. Se essa opção não aparecer, ative o Modo do desenvolvedor no canto superior direito da página de extensões.
3

Instale o script

Clique em Instalar no projeto desejado logo abaixo. O Tampermonkey abre uma tela própria: clique em Instalar de novo.

Depois é só abrir (ou recarregar com F5) o site do sistema e o script já estará funcionando.

Dúvidas e problemas

Se algo não funcionar, veja aqui.

Cliquei em “Instalar” e apareceu um monte de código

Isso significa que o Tampermonkey não está instalado ou não está ativo. Confira os passos 1 e 2, recarregue esta página e clique em Instalar novamente.

O script está instalado, mas não aparece nada no sistema
  1. Recarregue a página do sistema com F5.
  2. Clique no ícone do Tampermonkey: o script deve aparecer com o botão ligado (verde).
  3. Confira se a “Permitir scripts de usuário” do passo 2 está ativada. Ela costuma ser desligada quando o Chrome é atualizado.
Instalar manualmente (copiar e colar)
  1. No card do projeto, clique em Copiar código.
  2. Clique no ícone do Tampermonkey e em Criar um novo script…
  3. Apague todo o conteúdo do editor, cole o código (Ctrl+V) e salve com Ctrl+S.
Como recebo atualizações?

Como os scripts foram instalados por este site, o Tampermonkey verifica sozinho se há uma versão nova (cerca de uma vez por dia). Para forçar, clique no ícone do Tampermonkey e em Verificar atualizações de scripts. Outra opção é clicar em Instalar novamente aqui.

O Windows bloqueou o programa (.exe)

Na tela azul “O Windows protegeu o computador”, clique em Mais informações e depois em Executar assim mesmo. Se o antivírus da empresa apagar o arquivo, peça à TI para liberá-lo.

Como desativar ou remover um script

Clique no ícone do Tampermonkey e use o botão ao lado do nome do script para ligar ou desligar. Para remover, abra o Painel, marque o script e clique na lixeira.
